EQUIPAMENTOS

Para a realização do projeto, foram utilizados diferentes equipamentos e componentes que permitiram desenvolver e testar a solução

  • Microcontrolador ATmega328P (Placa Arduino Uno R3)
  • Display LCD 16x2 (com I2C)
  • Sensor de Luz LDR
  • Buzzer
  • Led Verde
  • Módulo RTC DS1307
  • LED Amarelo
  • LED Vermelho
  • Resistores (Valores adequados para os LEDs )
  • Protoboard e Jumpers de conexão
  • Sensor DHT22
  • Push Buttons
